생방송 기록이 늦게 나오거나 수집이 중단되면 어떻게 하나요?

먼저 기록 상태를 확인하세요. 생방송은 약 5분 분량씩 모아 순차적으로 받아쓰기하므로 결과가 바로 나오지 않을 수 있습니다. 실제 처리 시간은 PC 성능과 선택한 모델에 따라 달라집니다.

수집이 중단됐다면 지금까지 생성된 내용을 전체 기록 저장으로 보관하고, 앱에서 이어서 기록하기를 누르세요. 보관된 미완료 수집분을 처리한 뒤 현재 방송으로 연결합니다. 멈춘 동안 수집하지 못한 방송은 자동으로 되찾지 않습니다. 이후 다시보기가 게시되면 빠진 내용을 확인하거나 해당 부분을 다시 기록할 수 있습니다.

‘원음 확인 권장’은 받아쓰기 결과를 검토하라는 표시입니다. 실제 발언 누락이 확정됐다는 뜻은 아닙니다. 중요한 이름·숫자·발언은 원음과 대조해 주세요.

생방송에서는 우선 Small 모델을 사용하고, 불필요한 프로그램을 줄이며 PC가 절전 상태로 들어가지 않도록 확인하세요. 이런 조치가 모든 중단을 방지하는 것은 아닙니다.

관리자가 제 기록이나 사용 내역을 볼 수 있나요?

회의 기록·제목·메모는 내 PC에 저장되며, 외부인이나 운영자에게 자동으로 전송되거나 공개되지 않습니다. 운영자는 관리자 통계 화면에서 기록 내용이나 개인별 활용 내역을 확인할 수 없습니다. 운영 개선을 위해 개인을 구분하지 않는 전체 사용자의 날짜별 기록 실행·오류 횟수 합계만 90일간 보관합니다.

이름·고유 PC 번호·영상 주소·회의 제목·원문·오류 상세는 통계로 보내지 않습니다. 기록 시작·이어 기록하기를 실행 1회, 기록 작업 실패를 오류 1회로 집계합니다.

배포페이지에서는 쿠키나 지속적인 방문자 식별자 없이 날짜별 페이지 열림·설치 및 업데이트 버튼 클릭 합계를 90일간 집계합니다. 새로고침과 재방문도 포함하며 고유 방문자·설치 완료 수를 뜻하지 않습니다. GitHub 공개 배포 파일의 다운로드 누계도 운영자가 확인할 수 있습니다.

GPT·Claude에는 사용자가 직접 연결하고 AI에 공유를 선택한 기록만 읽도록 허용합니다. PC 안에 보관한 파일은 해당 PC와 Windows 계정의 접근 권한에 따라 보호됩니다.

GPT·Claude 연결은 꼭 해야 하나요?
선택 기능입니다. 연결하지 않아도 방송을 기록하고 TXT 파일로 저장할 수 있습니다. AI에서 활용하려면 앱 왼쪽의 GPT, Claude 연결하기 안내를 따르고, 원하는 기록에서 AI에 공유를 ON으로 켜고 확인 팝업에서 승인하세요. OFF로 끄면 그 기록의 공유가 해제됩니다. AI 서비스에 따라 지원 기능과 이용 조건이 다를 수 있습니다.
기록 날짜와 AI 공유 상태는 어디서 보나요?

메인 화면 아래 회의 기록 목록 오른쪽에서 처음 기록을 시작한 날짜와 시간(한국시간)을 확인할 수 있습니다. 이어서 기록해도 처음 시작한 시각은 유지됩니다.

기록의 AI에 공유 토글이 ON이면 해당 시점에 저장된 기록을 승인한 AI에 공유합니다. OFF로 끄면 공유가 해제됩니다. 원문이 추가되었다면 OFF로 끈 뒤 다시 ON으로 켜서 최신 기록을 공유하세요.

업데이트하면 기존 기록이 없어지나요?
기존 회의 기록·제목·메모·모델·AI 연결 설정은 유지됩니다. 최신 앱에서는 실행 시 새 버전과 변경 내용을 자동으로 알립니다. 업데이트를 선택하거나 나중에를 눌러 계속 사용하세요. 직접 확인하려면 실행 창이나 트레이 메뉴에서 업데이트 확인을 누르세요. 확인이 되지 않으면 프로그램을 종료한 뒤 수동 업데이트 파일을 실행하세요.
X를 눌러도 기록이 계속되나요?

네. 실행 창만 Windows 알림 영역(트레이)으로 숨기고 기록과 AI 연결은 유지합니다. 아이콘이 보이지 않으면 오른쪽 아래 ∧를 누르세요. StreamBrief 아이콘을 누르면 실행 창을 다시 열 수 있습니다. 오른쪽 클릭 메뉴에서 회의 기록 화면 열기·업데이트 확인·프로그램 종료를 선택할 수 있습니다.

실제로 종료하려면 실행 창 또는 트레이 메뉴의 프로그램 종료를 선택하세요.

AI 연결은 매번 다시 켜야 하나요?

한 번 켜면 사용 여부와 관계없이 30일 동안 유지하며, 앱을 다시 실행할 때 자동 연결합니다. 재실행으로 기간이 늘어나지는 않습니다. 내 PC 연결에서 종료일을 확인하거나 연결 해제 · 자동 연결 끄기로 중단하세요. 기존 버전에서 업데이트한 뒤에는 한 번 직접 켜면 적용됩니다.

앱을 실제로 종료한 동안에는 AI가 기록을 읽을 수 없습니다. AI 서비스의 재인증 요청은 별도이며, 원하는 기록의 AI에 공유는 직접 선택해야 합니다.

예상 시간과 진행률은 무엇을 기준으로 하나요?
예상 시간은 음성 처리 기준이며 수집·대기 시간은 제외합니다. PC 성능과 방송 음질에 따라 달라질 수 있습니다. 생방송 진행률은 현재 수집한 음성 중 처리한 비율이며, 방송 전체의 완료율은 아닙니다.
기록이 틀리거나 중간에 멈췄어요.

자동 음성 인식과 AI 보정에는 오류가 있을 수 있습니다. 중요한 이름·숫자·발언은 원음과 대조해 주세요. 방송 연결 오류가 나면 잠시 뒤 이어서 기록하기를 사용하고, 이미 저장된 내용을 먼저 TXT로 보관하세요.
