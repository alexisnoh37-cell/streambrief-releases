회의 기록과 개인별 활용 내역은 관리자 통계에 포함되지 않습니다

회의 기록·제목·메모는 내 PC에 보관됩니다. 운영 개선을 위해 개인을 구분하지 않는 날짜별 기록 실행·오류 횟수 합계만 90일간 보관합니다. 이름·고유 PC 번호·영상 주소·회의 제목·원문·오류 상세는 통계로 전송하지 않습니다. GPT·Claude에는 사용자가 직접 연결하고 AI에 공유를 선택한 기록만 읽도록 허용합니다.

처음 화면의 사용방법 튜토리얼은 어떻게 쓰나요?

강조된 항목을 직접 사용하거나 다음으로 따라가세요. 지금 하지 않을 단계는 이 단계 건너뛰기를 누릅니다. 이전으로 돌아가거나 지금 마치기로 끝낼 수도 있습니다.

마지막에 다시 자동 실행하지 않기를 체크하고 설정 저장하고 닫기를 누르면 다음 접속부터 자동으로 열리지 않습니다. 왼쪽 사용방법 튜토리얼 버튼으로 언제든 다시 시작할 수 있습니다. 이 설정은 해당 브라우저에 저장됩니다.

안내의 다음·건너뛰기를 누르는 것만으로 실제 기록·모델 설치·자료 공유가 시작되지는 않습니다.

Windows가 설치를 차단하면?

설치 파일은 미서명입니다. 차단 화면을 캡처해 제작 담당자나 전산 담당자에게 전달하세요. 기관 보안 설정을 임의로 끄지 마세요.

다시보기 영상 기록하기

영상 주소를 붙여넣고, 기록할 시작 위치와 길이를 정하세요.

다시보기 링크→주소·범위 입력→회의 기록 시작

  1. 기록할 영상의 주소를 복사합니다

    메인 화면의 다시보기 링크를 선택하세요. 오른쪽 전북특별자치도의회 인터넷방송 ↗을 누르고, 원하는 영상의 재생 창 주소 전체를 복사합니다.

  2. 주소와 기록할 범위를 입력합니다

    StreamBrief의 영상 재생 페이지 주소에 붙여넣으세요. 시작 시각과 분석할 길이를 입력합니다.

  3. 모델과 메모를 정합니다

    처음에는 모델을 Small로 고르세요. 메모는 ‘오전 예산 질의’처럼 같은 영상을 구분할 수 있게 적으면 좋습니다.

  4. 회의 기록을 시작합니다

    영상 정보·범위 미리보기로 확인한 뒤 회의 기록 시작을 누르세요. 미리보기를 거치지 않고 바로 시작할 수도 있습니다.

결과가 바로 나오지 않아도 기다려 주세요

원문은 대략 5분 구간마다 저장됩니다. 영상 수집과 음성 처리에 시간이 걸리며, PC와 모델에 따라 영상 길이보다 오래 걸릴 수 있습니다.

시간은 어떻게 입력하나요?

시작 시각의 01:00:00은 영상 1시간 지점입니다. 비우면 링크에 담긴 재생 위치를 사용합니다.

분석할 길이는 분 단위로 5~240 사이의 숫자를 5분 단위로 입력합니다. 240분은 4시간입니다. 영상 끝이 먼저 나오면 그 지점까지만 기록합니다.

링크에 &t=0 같은 글자가 있어도 되나요?

부가 타임스탬프는 자동으로 정리합니다. 시작 시각을 직접 입력했다면 그 값을 우선합니다. 의회 사이트의 첫 화면 주소 대신 영상별 재생 창 주소를 사용하세요.

제목 오른쪽에서 기록 진행 상태를 확인하세요

기록 진행 게이지에 현재 처리 비율과 전체·남은 예상 시간을 표시합니다. 음성 처리 기준의 예상으로 수집·대기 시간은 제외하며, PC 상태와 방송 음질에 따라 달라질 수 있습니다. 측정 전에는 계산 중으로 표시할 수 있습니다.

  1. 메인 화면에서 생방송 링크를 선택합니다

    방송 중인 위원회 조회를 누릅니다.

  2. 방송 중인 위원회를 고릅니다

  3. 생방송 회의 기록을 시작합니다

    생방송 회의 기록 시작을 누르세요. 시작한 시점부터 최대 4시간 수집합니다.

  4. 방송 수집을 끝내려면 수집 종료를 누릅니다

    수집 종료는 새 수집을 끝내는 버튼입니다. 이미 모아 둔 음성 처리가 남았다면 그 처리를 마칠 때까지 기다려 주세요.

일시정지한 동안의 방송은 기록되지 않습니다

다시 시작하면 남은 음성을 처리하고 현재 방송 시점부터 수집합니다. 정지 중 빠진 시간은 기록에 표시됩니다. 이미 지나간 방송을 자동으로 가져오지는 않습니다.

상황에 따라 이렇게 하세요

하고 싶은 일누를 버튼결과
잠깐 멈추기일시정지정리 후 멈춥니다. 정지 중 방송은 수집하지 않습니다.
수집만 끝내기수집 종료새 방송 수집을 끝내고 모아 둔 음성을 처리합니다.
다시 시작하기이어서 기록하기남은 처리를 마치고 현재 방송부터 수집합니다.
목록이 비어 있거나 처리가 많이 늦어지면?

실제 방송 중인지 의회 인터넷방송에서 확인하세요. 수집이 처리보다 너무 앞서가면 수집을 자동으로 멈추고 남은 음성을 보관할 수 있습니다. 화면 상태를 확인하고 이어서 처리하세요.

생방송의 진행률은 현재 수집한 음성 기준입니다

제목 오른쪽 게이지에서 수집한 음성 중 얼마나 처리했는지 확인합니다. 방송 전체의 종료 시각이나 완료율을 뜻하지 않습니다. 수집이 끝난 뒤에는 측정 자료가 있을 때 남은 처리 시간을 표시합니다.

5분당 걸린 시간은 어디서 보나요?

메인 화면의 나에게 맞는 모델 고르기에서 확인합니다. 이 PC에서 해당 모델로 실제 처리한 뒤부터 표시됩니다. 처음 실행하기 전에는 측정값이 없습니다.

표시되는 값은 수집·대기 시간을 제외한 음성 처리 시간입니다. PC 상태와 방송 음질에 따라 달라질 수 있습니다.

설치 필요로 나오면?

저장된 내용은 유지하면서, 미완료 부분을 이어서 처리할 수 있습니다.

  1. 진행 중인 기록에서 일시정지를 누릅니다

    일시정지를 누르면 현재의 짧은 음성 구간을 정리합니다. 버튼을 누른 즉시 멈추지는 않을 수 있습니다.

  2. 정리가 끝날 때까지 기다립니다

    화면이 정리 중이면 기다리세요. 정리가 끝난 뒤 저장·재개·삭제 기능을 사용할 수 있습니다.

  3. 계속하려면 이어서 기록하기를 누릅니다

    이어서 기록하기를 누릅니다. 다시보기는 선택한 범위 안의 미완료 부분을 이어서 처리합니다.

파일을 AI에 첨부해 정리하기

처음에는 TXT 파일을 직접 첨부하는 방법이 간단합니다.

TXT 저장→AI 대화에 첨부→보정·요약 요청

  1. 회의 기록을 TXT 파일로 저장합니다

    전체 기록 저장 · 메모장 파일 (.txt)을 눌러 받으세요.

  2. 본인의 GPT 또는 Claude 대화를 엽니다

    파일 첨부 기능에서 내려받은 TXT를 선택합니다. 계정과 서비스의 파일 첨부 지원 여부에 따라 사용할 수 있습니다.

  3. 원하는 작업을 요청합니다

    아래 요청문을 복사해 대화에 붙여넣으세요. 더 자세한 조건을 덧붙여도 됩니다.

이렇게 요청해 보세요

첨부한 자료는 의회 방송의 자동 회의 기록입니다. 문맥에 맞는 보정안을 제시하되 빠진 발언을 지어내지 마세요. 이름·금액·날짜가 확실하지 않으면 불확실하다고 표시하세요. 보정 전후와 수정 이유를 구분하고, 마지막에 핵심 질의·답변·후속 조치를 요약해 주세요. 원음을 직접 들었다고 말하지 마세요.

이름·숫자·결정 사항은 직접 확인하세요

원문은 자동 음성 인식 결과이고, AI 보정도 틀릴 수 있습니다. 중요한 내용은 원음이나 확정 회의록과 대조하세요. StreamBrief 자체가 원문을 자동으로 보정하거나 요약하지는 않습니다.

GPT·Claude 연결하기

선택 기능입니다. 처음 연결은 세 단계로 나누어 따라 하세요.

1. AI 서비스에 주소를 등록합니다

  1. StreamBrief에서 연결 창을 엽니다

    왼쪽 위 GPT, Claude 연결하기를 누릅니다.

  2. 고정 MCP 주소를 복사합니다

    연결 주소 복사를 누르세요. MCP 주소는 GPT·Claude가 이 프로그램을 찾아오는 연결 주소입니다.

  3. GPT 또는 Claude에서 사용자 지정 연결을 추가합니다

    복사한 주소를 서버 주소에 붙여넣습니다. 인증은 OAuth, 클라이언트 등록 방식을 묻는다면 자동 등록(DCR)을 선택하세요. 계정·조직에 따라 메뉴와 지원 여부가 다를 수 있습니다.

등록할 주소

https://streambrief-relay.isn0522.workers.dev/mcp

주소는 끝의 /mcp까지 복사하세요

임시 주소가 아닌 위의 고정 주소를 등록합니다. 별도의 관리자 PC 등록 코드는 입력하지 않습니다.

2. 본인 PC에서 연결 요청을 승인합니다

  1. 외부 승인 화면의 코드를 복사합니다

    GPT·Claude 연결 과정에서 열린 승인 화면에서 승인 코드 복사를 누릅니다.

  2. StreamBrief에서 내 PC 연결을 엽니다

    내 PC 연결을 누르고, 연결이 꺼져 있으면 AI 연결 켜기를 누릅니다.

  3. 승인 코드를 붙여넣습니다

    Claude·GPT 승인 코드 칸에 붙여넣고 본인 PC로 연결 요청 가져오기를 누릅니다.

  4. 본인이 시작한 요청을 확인하고 승인합니다

    요청 코드와 콜백 주소를 외부 승인 화면과 대조하세요. 모르는 요청은 승인하지 마세요. 승인 후 AI 서비스의 연결 화면에서 완료 여부를 확인합니다.

두 종류의 코드를 헷갈리지 마세요

관리자 PC 등록 코드는 필요 없습니다. 여기서 쓰는 승인 코드는 지금 GPT·Claude에서 시작한 연결 요청을 본인 PC에 가져오기 위한 코드입니다.

3. 읽게 할 기록을 직접 공유합니다

  1. 완료되거나 일시정지된 기록을 엽니다

    왼쪽 회의 기록 목록에서 공유할 기록을 선택합니다.

  2. 기록 제목 아래 AI 공유를 ON으로 켭니다

    AI에 공유 토글을 눌러 확인 팝업에서 공유를 승인하세요. ON이면 해당 시점에 저장된 기록을 공유하고, OFF면 공유를 해제합니다. 연결만으로 모든 기록이 자동 공유되지는 않습니다.

  3. AI 대화에서 기록을 읽어 달라고 요청합니다

    “공유한 회의 기록을 찾아 모든 페이지를 읽어줘”라고 요청하세요. 결과의 회의 제목과 처리 범위가 원하는 기록과 맞는지도 확인하세요.

아직 AI가 연결되지 않았다고 나오면?

공유 버튼을 눌렀을 때 연결 안내가 뜨면 예를 눌러 GPT·Claude 연결 창으로 이동하세요. 아니요는 창을 닫습니다. 연결과 승인을 마친 뒤 원하는 기록에서 AI에 공유를 다시 누르세요. 연결 창을 여는 것만으로 기록이 공유되지는 않습니다.

PC와 StreamBrief가 켜져 있어야 읽을 수 있습니다

AI 연결 켜기를 한 번 누르면 그 시점부터 30일 동안 앱 사용 여부와 관계없이 연결 유지 기간을 보존합니다. 앱을 다시 켜면 남은 기간 동안 자동 연결하며, 재시작·재접속으로 기간이 늘어나지 않습니다. 내 PC 연결에서 유지 종료 시각을 확인하세요. 앱이 꺼져 있으면 AI가 기록을 읽을 수 없습니다.

30일이 지나거나 직접 해제했다면 AI 연결 켜기를 다시 누르세요. 기존 버전에서 업데이트한 뒤에도 한 번 직접 켜면 적용됩니다. AI 서비스의 승인 기한이나 재인증 요청은 별도입니다.

공유를 취소하거나 내용을 새로 반영하려면?

공유 해제는 해당 자료의 공유를, 연결 권한 해제는 해당 AI의 읽기 권한을 취소합니다. 연결 해제 · 자동 연결 끄기는 통신과 다음 실행 시 자동 연결을 중단하며 승인·공유 설정은 유지합니다. 프로그램을 종료하는 것만으로 자동 연결 설정이 해제되지는 않습니다. 공유 사본은 이 PC에 최대 30일 보관합니다. 원문이 추가되었다면 AI에 공유를 OFF로 끈 뒤 다시 ON으로 켜서 최신 기록을 공유하세요. 이미 AI가 읽은 내용은 회수되지 않습니다.

내 자료는 어디로 전달되나요?

직접 공유한 텍스트를 외부 AI가 읽고 Cloudflare가 통신을 중계합니다. 중계 서버에는 원문을 저장하지 않으며 오디오·모델·전체 DB를 제공하지 않습니다. 이미 AI가 읽은 내용은 회수할 수 없습니다. 본인 Windows 계정과 본인 AI 계정으로 사용하세요. AI 서비스의 이용 제한은 별도로 적용됩니다.

업데이트·종료·제거하기

업데이트는 브라우저가 아닌 작은 StreamBrief 실행 창에서 합니다.

1.08에서 업데이트 확인 오류가 계속된다면

작은 실행 창에서 프로그램 종료를 누르고 StreamBrief-__DISPLAY_VERSION__-Update.exe를 직접 내려받아 실행하세요. 현재 버전은 GitHub API 대신 공개 안내 파일로 새 버전을 확인합니다. __DISPLAY_VERSION__ 배포 페이지 열기 ↗

새 버전으로 업데이트하기

변경사항은 실행 창 안에서 확인합니다

앱을 실행하면 최신 버전을 자동으로 확인합니다. 새 버전의 간단한 변경사항은 별도 팝업 없이 업데이트 확인·변경 내용 버튼 아래에 표시됩니다. 업데이트를 누르면 추가 확인창 없이 다운로드·검증을 시작합니다. 진행 상태나 진행할 수 없는 이유도 같은 창에 표시합니다. 지금 업데이트하지 않으려면 버튼을 누르지 않고 계속 사용하면 됩니다. 조회가 실패해도 회의 기록은 계속 사용할 수 있습니다.

  1. 작업을 끝내거나 일시정지합니다

    회의 기록과 엔진 설치를 마치세요. 일시정지했다면 정리가 끝날 때까지 기다립니다.

  2. 작은 실행 창에서 버전을 확인합니다

    업데이트 확인을 누릅니다. 새 버전이 있으면 버튼 아래에서 간단한 변경사항을 볼 수 있습니다. 변경 내용을 누르면 같은 영역에서 다시 읽을 수 있습니다.

  3. 업데이트를 누르고 기다립니다

    업데이트를 누르면 다운로드·검증 후 프로그램을 종료하고 교체한 뒤 다시 실행합니다. 도중에 창을 강제로 닫지 마세요.

기록과 모델은 그대로 유지합니다

회의 기록·제목·메모·모델·AI 연결 설정을 보존합니다. 모델을 매번 다시 내려받지 않습니다. 30일 연결 유지 기간이 남아 있으면 다시 실행할 때 자동 연결됩니다. 기간이 끝났거나 직접 해제했다면 AI 연결 켜기를 누르세요. 기존 버전에서 처음 업데이트한 뒤에는 한 번 직접 켜야 합니다.

창 숨기기 · 트레이에서 다시 열기

실행 창의 X는 종료 대신 Windows 오른쪽 아래 알림 영역(트레이)으로 숨깁니다. 기록과 AI 연결은 계속 유지합니다. 아이콘이 보이지 않으면 작업 표시줄의 ∧를 누르세요. StreamBrief 아이콘을 누르면 실행 창이 다시 열립니다. 오른쪽 클릭 메뉴에서 회의 기록 화면 열기, 업데이트 확인, 프로그램 종료도 선택할 수 있습니다. 트레이를 사용할 수 없으면 작업 표시줄로 최소화합니다.

프로그램 종료하기

트레이 메뉴 또는 작은 실행 창에서 프로그램 종료를 누릅니다. 기록 중이었다면 처리 내용을 정리하고 종료할지 확인합니다. 종료가 끝날 때까지 기다리세요.

프로그램 제거하기

Windows의 설정 → 앱 → 설치된 앱 → StreamBrief → 제거를 선택합니다. 제거해도 사용자 폴더의 기록·메모·모델은 보관합니다.

업데이트가 없거나 실패했다고 나오면?

새 배포본이 아직 없을 수 있습니다. 인터넷 연결 문제나 파일 검증 실패라면 기존 프로그램을 계속 사용할 수 있습니다. 나중에 다시 확인하세요. 성공한 조회 결과는 5분간 재사용합니다. 요청 제한·인증서·응답 지연 안내가 나오면 해당 안내에 따라 확인하세요. 소스 폴더에서 실행하는 버전은 앱 내 업데이트 대신 소스를 갱신합니다.

작은 실행 창에서 회의 기록 화면 열기를 누르세요. 실행 창이 없다면 바탕화면의 StreamBrief를 더블클릭합니다. 계속 안 열리면 프로그램을 종료하고 다시 실행하세요.

영상 주소가 거부돼요

전북특별자치도의회 공식 다시보기의 영상별 재생 창 주소 전체인지 확인하세요. 사이트 첫 화면 주소나 다른 사이트의 주소는 사용할 수 없습니다.

한참 기다려도 글이 안 나와요

첫 결과는 대략 5분 구간의 수집·음성 처리가 끝난 뒤 나옵니다. Small·5분으로 짧게 시험하고, 다른 큰 프로그램을 종료해 보세요. Large와 병행은 더 오래 걸릴 수 있습니다.

The read operation timed out 오류가 나와요

방송 데이터를 기다리다가 제한 시간을 넘겼다는 뜻입니다. 방송 서버 지연이나 네트워크 끊김 등이 원인일 수 있습니다. 기존 기록은 보존됩니다. 잠시 후 이어서 기록하기를 눌러 미완료 구간을 다시 처리하세요.

이 오류는 음성 인식 정확도나 GPT·Claude 연결 오류와는 별개입니다.

모델이나 도구가 설치 필요로 나와요

설치가 끝났는지 확인하고 프로그램을 다시 실행하세요. 로컬 엔진에 빠진 항목이 표시되면 해당 설치하기를 누릅니다. 기록 중이라면 먼저 일시정지하고 정리가 끝나야 합니다.

GPT·Claude가 다른 회의를 말해요

원하는 기록에서 AI에 공유를 눌렀는지 확인하세요. AI에게 공유된 회의의 제목·범위를 확인하고 모든 페이지를 읽어 달라고 요청하세요. 도구를 호출하지 않고 이전 대화만 요약한 답변은 현재 기록을 가져온 결과가 아닙니다. 불분명하면 원하는 TXT를 직접 첨부하세요.

이 버전은 어디까지 검증했나요?

Windows 자동 검증에서 실제 설치·실행 창·음성 변환·두 모델의 짧은 음성 인식·업데이트·교체 실패 시 프로그램 보존·재설치와 제거 후 기록 보존을 확인했습니다. 실제 8GB PC의 4시간 연속 사용과 병행의 장시간 성능, 실제 GPT·Claude 계정 연결은 별도 확인 대상입니다.

관리와 도움말

기존 폴더의 기록 옮기기

이전에 프로젝트 폴더에서 실행하던 사용자를 위한 안내입니다.

기존 폴더를 먼저 백업하세요

설치판은 별도의 사용자 저장 폴더를 사용합니다. 기존 기록이 자동으로 이동하거나 두 폴더의 기록이 자동으로 합쳐지지는 않습니다.

  1. 기존 기록을 파일로 저장하고 프로그램을 종료합니다

    필요한 기록을 TXT로 저장한 다음 기존 프로그램을 완전히 종료하세요. 기존 프로젝트 폴더 전체를 별도 위치에 복사해 백업합니다.

  2. 설치판을 설치하되 아직 실행하지 않습니다

    설치 마지막 화면의 StreamBrief 실행하기 선택을 해제하고 마칩니다.

  3. 새 사용자 저장 폴더를 엽니다

    파일 탐색기 주소 칸에 아래 경로를 붙여넣고 Enter를 누르세요.

  4. 기존 data 폴더를 복사합니다

    기존 프로젝트 안의 data 폴더 전체를 새 저장 폴더로 복사합니다. 같은 이름의 data 폴더가 이미 있으면 덮어쓰지 말고 담당자에게 문의하세요.

  5. 설치판을 실행해 기록을 확인합니다

    완료된 기록과 메모가 보이는지 확인하세요. 이전에 처리 중이던 기록은 TXT를 보관하고 새 기록으로 시작합니다.

파일 탐색기에 입력할 경로

%LOCALAPPDATA%\StreamBrief

기존 AI 연결 설정은 같은 PC·같은 Windows 사용자 계정에서만 옮깁니다. 다른 PC로 옮기거나 폴더가 여러 개라면 담당자와 함께 진행하세요.

이미 설치판을 사용 중이라면?

새 버전으로 업데이트하거나 재설치해도 기존 사용자 폴더의 기록을 유지합니다. 이 항목은 프로젝트 폴더로 실행하던 기록을 설치판으로 옮길 때만 참고하세요.
