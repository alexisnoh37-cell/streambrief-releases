# StreamBrief

전북특별자치도의회 인터넷방송의 다시보기·생방송을 PC에서 회의 기록으로 남기는 Windows 프로그램입니다.

**[설치·업데이트·사용 안내 페이지 열기](https://alexisnoh37-cell.github.io/streambrief-releases/)**

**회의 기록은 내 PC에 보관됩니다.** 관리자 통계 화면에서는 회의 기록·제목·메모나 개인별 활용 내역을 확인할 수 없습니다. 개인을 구분하지 않는 날짜별 기록 실행·오류 합계만 90일간 집계합니다. GPT·Claude에는 사용자가 직접 연결하고 **AI에 공유를 ON**으로 켜고 승인한 기록만 읽도록 허용합니다.

## 설치와 업데이트

1.13부터 기록 목록 오른쪽에 최초 시작 날짜·시간을 표시하고 AI에 공유를 ON/OFF 토글로 관리합니다. OFF로 끄면 해당 기록의 공유가 해제됩니다. 원문이 추가되면 OFF → ON으로 새로 공유하세요.

- 처음 사용할 때는 [최신 배포 페이지](https://github.com/alexisnoh37-cell/streambrief-releases/releases/latest)의 **StreamBrief-버전-Setup.exe**를 받으세요. Small·Large 모델과 필요한 실행 도구가 포함됩니다.
- 1.12부터는 실행 시 새 버전과 변경 내용을 자동으로 알려주며, **업데이트 / 나중에**를 선택할 수 있습니다. 직접 확인하려면 실행 창이나 트레이 메뉴의 **업데이트 확인**을 누르세요. 회의 기록·메모·모델·AI 연결 설정은 보존합니다.
- 실행 창의 **X**는 트레이로 숨기며 기록·AI 연결은 유지합니다. 트레이 아이콘에서 다시 열거나 **프로그램 종료**를 선택하세요.
- 공통 AI 연결을 한 번 켜면 **30일 동안 재실행 시 자동 연결**합니다. 기존 사용자는 업데이트 후 한 번 직접 켜면 적용되며, **내 PC 연결**에서 종료일 확인·해제가 가능합니다.
- **Update.exe는 기존에 설치한 프로그램의 업데이트용**입니다. 처음 설치할 때는 Setup.exe를 선택하세요.
- [항목별 사용 가이드(HTML) 다운로드](https://github.com/alexisnoh37-cell/streambrief-releases/releases/latest/download/StreamBrief-User-Guide.html): 내려받아 더블클릭하면 목차별 안내·검색·AI 연결 순서를 볼 수 있습니다. 인터넷 없이도 열 수 있습니다.
- [60초 설명영상](https://github.com/alexisnoh37-cell/streambrief-releases/releases/latest/download/StreamBrief-Quick-Guide-60s.mp4)으로 기본 사용 순서를 확인할 수 있습니다. 앱 왼쪽의 **사용방법 튜토리얼**에서는 단계별 안내를 따라 하거나 건너뛸 수 있습니다.
- 사용방법과 SHA256 체크섬, 검증 보고서는 각 배포 페이지에 포함합니다. 설치 폴더의 licenses에서 포함된 구성품의 라이선스를 확인할 수 있습니다.

이 저장소에는 배포 파일과 사용 안내만 제공합니다. 소스와 사용자 회의 기록은 업로드하지 않습니다.

자동 회의 기록의 이름·수치·누락 여부는 원음과 대조해 검토하세요. 기관의 보안 정책에 의해 실행이 차단되면 담당자에게 문의하세요.


## 다운로드 페이지 관리

공개 페이지는 `site/index.template.html`의 디자인을 사용하며, 정식 배포의 설치·업데이트·HTML 안내서·60초 영상 네 가지 파일을 확인한 뒤 생성합니다. 소스 앱 저장소와 직원 기록은 읽지 않습니다. 공개 배포 작업과 영상 업로드 작업이 성공하면 페이지도 자동 갱신하며, 하루 한 번 확인하거나 Actions의 **Publish user download page**를 수동 실행할 수도 있습니다. 방문자는 GitHub API를 조회하거나 로그인할 필요가 없습니다.

페이지를 중단하려면 저장소 Settings → Pages에서 사이트를 게시 해제하고 페이지 배포 워크플로를 비활성화하면 됩니다. 기존 Releases의 파일과 앱 업데이트 경로는 그대로 유지됩니다.

## 익명 배포페이지 통계

운영 중계서버의 `/site-events` 기능을 먼저 배포한 뒤 이 변경을 게시합니다. 페이지가 처음 표시될 때 열림 1회, 설치·업데이트 링크를 누를 때 클릭 1회를 전송합니다. 방문자 식별자·쿠키·localStorage·페이지 URL·Referrer·계정·원문은 보내지 않습니다. 일회성 전송 번호는 재전송 중복 방지용이며 방문자를 구분하지 않습니다. 한국시간 날짜별 합계만 90일 보관하고 새로고침·재방문도 포함합니다. DNT·GPC 설정, 차단·오프라인·수신 한도로 빠질 수 있습니다. 시험 미리보기와 다른 경로에서는 전송하지 않습니다.

GitHub 파일 다운로드 누계는 관리자 인증 후 중계서버가 최대 1시간 간격으로 조회합니다. 사용자 브라우저는 GitHub API를 호출하지 않습니다. 클릭·파일 다운로드·설치 완료·고유 사용자는 서로 다른 지표입니다.

## 검증된 빌드 전달

비공개 소스 저장소에서 실제 Windows 설치·업데이트 검증을 마친 8개 배포 파일만 전달합니다. Actions artifact 용량 한도가 있는 경우 비공개 draft release의 ZIP을 임시 경로로 사용합니다. 공개 게시 workflow는 고정 Azure artifact 또는 해당 소스 저장소의 GitHub release-assets CDN 주소만 허용하고, 전달 ZIP SHA256·source_commit·파일 목록·설치 검증 보고서·각 EXE 크기/해시를 검증합니다. 비공개 소스·사용자 자료는 공개 저장소로 옮기지 않습니다.

### 1.13 수정 배포

사용자 표시·다운로드 파일명은 1.13, 내부 패키지 태그는 v1.0.15입니다. 기존 앱의 숫자 파일명 계약을 위한 동일 바이너리 StreamBrief-1.15-Update.exe도 게시합니다. 페이지의 설치·수동 업데이트 버튼은 1.13 파일을 사용합니다. 앱의 짧은 변경 요약은 update-info.json에, 공개 배포 설명은 release-notes.md에 따로 관리합니다. 기존 v1.0.13·v1.0.14 파일을 덮어쓰지 않습니다.
